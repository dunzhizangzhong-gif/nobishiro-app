# /step25-ui — MobbinでUI方針確定

specs/spec.md の「8. 画面構成」を読み、Mobbin MCPで類似の実例パターンを調査してください。

各画面についてMobbinの実例(3〜5パターン)をもとに:
- よく使われているレイアウトの型
- 情報の見せ方・階層の作り方の共通パターン
- 避けたほうがよい失敗パターン(あれば)
を整理し、specs/ui-direction.md に以下の形式で保存してください。まだ実装はしません。

【採用するレイアウトの型】(画面ごとに1行)
【避けるパターン】
【自分たちのブランド表現】(配色・タイポグラフィ。spec.mdのデザイン仕様と整合させる)

調査中に気づいた仕様の抜け(空状態・エラー状態・戻る挙動など)は、
口頭で終わらせず必ず specs/spec.md に書き戻し、変更点を一覧で報告してください。
Mobbinの画面はパターン(情報構造・導線)の参考のみ。表現の模倣は提案しないこと。
