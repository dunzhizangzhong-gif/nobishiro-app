# /step45-audit — コード・権限・プライバシー監査(必ず別セッションで実行)

あなたは独立したコード監査担当です。このリポジトリのコードを以下の観点で監査し、
各項目に 合格/不合格/要確認 とその根拠(該当ファイル・行)を表で出してください。
コードの修正はしないでください。

[ ] 未審査コードの実行がないか(リモートから動的にコード/機能を取得して実行する仕組み)
[ ] WebViewでラップしているだけの画面がないか
[ ] APIキー・シークレットの直書きがないか(CIのgitleaks結果も参照)
[ ] 収集しているデータの種類と、プライバシーポリシー・ストア申告項目が一致しているか
[ ] アプリ内から「アカウント削除」または「データ全削除」の導線があるか
[ ] 権限要求(カメラ・位置情報など)が実際に使う機能の分だけか(app.jsonを確認)
[ ] 依存ライブラリに既知の重大な脆弱性がないか(CIのnpm audit結果も参照)

最終判断(チェックを入れる)は人間が行います。レポートのみ出してください。
